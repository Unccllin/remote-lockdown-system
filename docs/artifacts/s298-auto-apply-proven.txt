  apply_pending_update(root)   none|applied|corrupt|failed — re-checks the SHA-256 against the hash

--- [4] a packaging gap this exposed ---
  The first rebuilt lockdown-service.exe would not start: SCM error 1053 ("did not respond to the
  start or control request in a timely fashion"). Cause: pywin32 was not installed in the build
  environment, so the frozen service lacked servicemanager/win32serviceutil — the module catches
  ImportError and sets PYWIN32_AVAILABLE=False, which is graceful at import time and fatal as an
  SCM host. agent/requirements.txt lists cryptography and requests only. Fixed locally with
  `pip install pywin32` + `pyinstaller --clean` (a cached build kept the old hash and had to be
  discarded: same hash 94c91a0e, no pywin32 — --clean produced 9,495,232 B / cbf3e8d3).
