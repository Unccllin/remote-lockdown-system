--- [5] verdict ---
  PROVEN on hardware: offer -> download -> SHA-256 -> Ed25519 verify (pinned key) -> swap -> new
  binary running -> server sees 1.0.1. The update trust root works end to end.
  OPEN: the apply step has no automatic consumer on a service-based install. Only
  agent/watchdog.py reads .update_pending, and the installer's service path does not run it
  (installer.py installs "the scheduled task watchdog" for the other install mode). Until that
  is reconciled, an update sits verified-but-unapplied on any service install — a silent
  no-op that looks like success from the log.
