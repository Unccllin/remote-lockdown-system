--- [3] the structural finding: the dev scaffold never served the UI ---
  server/src/index.js (production entry) has served dashboard/dist since the S294-era prod bug
  ("the image built dashboard/dist and served none of it"). server/dev-start-sqlite.js — the
  scaffold every hardware session has used, including the one MOLE has been polling all day —
  mounted /api/* and /metrics only. So "the server" meant two different things depending on the
  entry point, and a UI demo against the dev server could only ever get 404s.

  Now it mounts the built dist with the same cache rules as src/index.js (hashed assets
  immutable, index.html never cached) and the same SPA fallback.
