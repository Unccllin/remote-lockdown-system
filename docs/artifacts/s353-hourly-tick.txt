# S353 — hourly tick, daily backup gate — 2026-11-24T14:25:35Z

## Change
```
wrangler.toml   crons = ["0 3 * * *"] -> ["0 * * * *"]   (hourly)
worker.ts       shouldRunBackup(controller): backup only when UTC hour == BACKUP_HOUR_UTC (3)
                unknown scheduledTime -> run (a silently-stopped backup is the worse failure)
reason          a stale-device alert up to 24 h late is the wrong trade for a lockdown product;
                a full export every hour is the wrong trade at scale (it walks the whole store)
```
