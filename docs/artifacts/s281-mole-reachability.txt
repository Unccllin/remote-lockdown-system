--- [8] conclusion ---
  Ping reaches this host (TTL 64, 2 ms). TCP 3001 is DROPPED by this host's own ufw
  (default INPUT policy DROP, and 3001 has no allow rule). The server is listening on
  *:3001 (0.0.0.0), MOLE has no portproxy at all, and no proxy is needed: this host
  holds 192.168.1.43 directly. The fix is one rule on THIS host, and it needs root:

    sudo ufw allow 3001/tcp
    # or, LAN-only:  sudo ufw allow from 192.168.1.0/24 to any port 3001 proto tcp

  Not run: passwordless sudo is unavailable in this session (sudo -n -> 'a password is required').
