## 8. Two analyzer rules contradict each other for a lock handle, so one is suppressed
   'unwrapped open() throws'  vs  SIM115 'use a context manager for opening files'.
   The handle must outlive the acquire/release pair, so it cannot be confined to a
   `with` body and still span the yield. Resolution: open inside try/except SystemExit
   (a lock that cannot be opened must fail loudly, never silently degrade to unlocked)
   and put `# noqa: SIM115` on that one line with the reason above it.
   The msvcrt branch was fixed at the source instead: getattr(msvcrt, 'locking', None).
   On a POSIX host msvcrt is a stub without those names, and S342's code read them
   directly — which is why both scripts reported 5 Pyright errors until this session.
