--- [5] what the workflow got wrong, and how it was caught ---
The worker's first pass dropped the recipe TAB on Makefile:290, so `make` could not parse the file
at all — every target died with "missing separator". The worker's own report said "make
lint-workflows not re-run here but YAML valid", which is exactly the wrong check (the failure is
Makefile syntax, not YAML). The oracle blocked on it, the fix round restored `^I` (verified with
`sed -n 290p Makefile | cat -A`), and the re-review approved. Two cosmetic nits the oracle called
harmless were also reverted by the parent: quote style flipped on two import lines in
tests/MapPage.test.jsx and tests/setup.jsx, and an `&apos;` inside a JSX comment in HealthPage.jsx
(never rendered, but reads as markup). Diff after that: 21 files, +59/-51 in the gate+lint commit.
